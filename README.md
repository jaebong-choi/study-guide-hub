# Study Guide Hub

호주·영국·캐나다 유학 진단 사이트 3개와 어학연수 지도(ESL Study Map)를 하나로 묶는 허브(랜딩) 사이트.
특정 유학원과 무관한 무료 정보 가이드 포지셔닝.

## 설정값

`js/main.js` 상단 `CONFIG`에서 브랜드명·Tally 폼 ID·카카오 채널 URL·문의 이메일을 설정합니다.
GA4는 `index.html` 하단 주석을 해제하고 ID를 교체하세요.
OG 이미지는 `images/og-image.png`(1200x630)로 교체하면 됩니다.

## 배포 (GitHub Pages)

1. `git push origin main`
2. GitHub 리포 Settings → Pages → Branch를 `main` / root로 설정
3. https://jaebong-choi.github.io/study-guide-hub/ 에서 확인
