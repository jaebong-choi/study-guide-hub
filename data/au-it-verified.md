# IT 계열 세부전공 — 진단 카드용 확정 데이터 (2026-08-03)

학비는 **CRICOS 등록부**(과정 총액 ÷ 기간 → 연간 환산), 영어는 각 대학 공식 문서
(`au-english-general.md`), **석사 지원 자격은 각 과정 페이지 원문**으로 확인했다.

계열 구성: IT 일반(기존) · 컴퓨터사이언스 · 사이버보안 · AI·데이터사이언스 · 소프트웨어공학

## ⚠ 기존 항목 이름을 바꿨다

`IT 및 사이버보안 (IT/Cyber Security)` → **`IT 일반 (Information Technology)`**.
사이버보안이 세부 전공으로 따로 생기는데 상위 항목 이름에도 사이버보안이 들어가 있으면
보기 목록이 겹쳐 읽힌다. **공유 링크 코드 `I`는 그대로 두었고**, `decodeProfile`은 코드로
키를 찾으므로 기존 링크(`#r=...-I-...`)는 그대로 열린다. 검증 완료.

## 소프트웨어공학 (Software Engineering)

⚠ **백로그에는 "컴퓨터공학"으로 적혀 있었는데 이름을 바꿨다.** 호주에서 그 이름의 학위는
거의 없고, 실제로 개설되는 건 Software Engineering과 Computer Systems Engineering이다.
CRICOS 전수 확인 결과 "Computer Engineering"이라는 학위명은 검증 대상 학교에 하나도 없었다.

멜버른대(69,500)·RMIT 등은 영어 요건을 못 읽어서 뺐다.

## 이 계열의 판단 축

**IT는 "학교 등급"보다 "전공 이름"이 학비를 정한다.** 같은 WSU 안에서도 사이버보안 32,500 ·
컴퓨터사이언스 38,200 · 데이터사이언스 40,100으로 갈리고, UNSW는 사이버보안 63,200이다.
학비 차이가 두 배인데 졸업 후 직군은 겹친다. **그래서 "무슨 전공이냐"를 먼저 정하고
학교를 고르는 순서가 맞다.**
