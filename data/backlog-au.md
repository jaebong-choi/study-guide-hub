### CRICOS 갱신 방법 — 다음에 그대로 쓸 것
1. data.gov.au의 CRICOS 데이터셋에서 `cricos-courses.csv`를 받는다(약 7MB, 26,000행).
   과정별 **Tuition Fee(과정 총액)·Duration(주)·Course Level·Expired**가 다 들어 있다.
   웹(cricos.education.gov.au)은 ASP.NET 포스트백이라 긁지 말 것 — CSV가 정답이다.
2. Expired=No만 쓴다. 연간 학비 = Tuition Fee ÷ (Duration주/52). 26주 미만 과정은 제외.
3. 학교 단위 값은 **25~75% 구간**(캐나다 컬리지와 같은 원칙), 100단위 반올림.
   UG = Bachelor (Honours 포함) · PG = Masters (Coursework) · 컬리지 = Diploma+Advanced Diploma.
4. **CSV의 기관명은 사이트 표기와 다르다**: RMIT는 `Royal Melbourne Institute of Technology`,
   TAFE NSW는 `Technical and Further Education Commission`(00591E), UWA·맥쿼리 등은

   과정명 Hotel|Hospitality|Culinary 필터로 걸렀다(n=4).
5. 공식 요금표 PDF가 있는 학교(UOW·플린더스)는 PDF 값을 유지한다 — CRICOS보다 학교 공시가 우선.

## 게시판 (2026-08-03 개편)

`guide/au.html`의 유학 정보가 **카드 나열에서 게시판(제목 목록)으로 바뀌었다.**
종로유학원 게시판처럼 글이 수십 편으로 늘어나도 화면이 감당되게 하는 게 목적이다.

- **한 페이지 10행**, 번호는 최신 글이 큰 번호(게시판 관습). 페이지 넘김은 11편째부터 나타난다.
- **분류 필터(버튼)**: 전공 선택 · 진학 경로 · 학비·비용 · 영어·요건 → `articles-au.json`의 `category`
- **대상 필터(드롭다운)**: 학부 · 석사 → 기존 `tracks` 필드를 그대로 쓴다
- 마크업은 `build-uni.ps1`이 `<div class="info-board">` 안을 통째로 갈아 끼운다. **손으로 고치지 말 것.**
- ⚠ **치환 끝은 `<!--/board-->` 주석으로 잡는다.** 게시판 마크업 안에 `</div>`가 있어서
  "첫 `</div>`까지"로 끊으면 뒤가 남고 다음 빌드에서 통째로 덧붙는다. 실제로 한 번 겪어
  행이 13→28개가 됐다. 빌드를 연속 3회 돌려 행 수가 그대로인지로 확인하면 된다.
- 스타일은 `css/guide.css`의 `.board-*`, 동작은 `js/guide.js` 맨 아래 IIFE.
- ⚠ **`.board-row`에 `display:grid`를 줬기 때문에 `hidden` 속성이 UA 기본값에 밀린다.**
  `.board-row[hidden]{display:none}`가 없으면 필터·페이지가 JS상으로만 동작하고 화면은 그대로다.
  실제로 한 번 당했다. 행 표시를 건드릴 때 이 규칙을 지울 것인지 확인할 것.

진단 결과(au-study-guide)의 유학 정보도 **같은 목록형**으로 맞췄다(`.rboard-*`). 결과에는 이미
전공·트랙으로 걸러진 글만 나오므로 **필터와 페이지 넘김은 두지 않았다.**
분류 배지 문구는 `i18n.js`의 `cat_*` 키에 있다.

### ⚠ 필자가 전 직장(coei)에서 쓴 글이라는 점
사용자가 coei 게시판 글의 **원저자다.** 저작권은 전 직장에 있고, 같은 사람이 썼다는 사실 때문에

### 조회 방법 — 다음에 그대로 쓸 것

1. **플린더스는 같은 도메인에서 `fetch`로 한 번에 긁힌다.** 코스 페이지를 하나 열어 두고
   `fetch` 루프 → `DOMParser` → 본문 텍스트에서 정규식. 23개를 한 호출로 처리했다.
2. ⚠ **페이지에 국내(CSP)·국제(FFP) 금액이 같이 들어 있다.** 그냥 첫 `$`를 잡으면
   **국내 보조금 금액($4,738 같은)이 잡힌다.** 반드시 `(FFP)` / `Full fee p...` 쪽을 골라야 한다.
3. ⚠ **`postgraduate-*` URL 하나에 여러 학위가 묶여 있다**(Grad Cert·Grad Dip·Master).
   금액이 2~3개 나오므로 자동 추출이 모호하다. **이 페이지들은 눈으로 확인해야 한다.**
   `Domestic` / `International` 아코디언을 펴야 국제 금액이 본문에 들어온다.
4. 플린더스·UQ 모두 403 없이 실제 크롬에서 읽힌다.

### 🟢 UTS 뚫었다 — 공식 학비 검색기 쓰는 법

코스 페이지는 **국내 금액만** 보여준다("Indicative total tuition fee for domestic students").
학생 유형 드롭다운을 눌러도 국제 금액으로 안 바뀐다. **정답은 공식 검색기다.**

**`https://cis.uts.edu.au/fees/course-fees.cfm`**
1. `fee_type` = **`IFUG`**(국제 학부) 또는 **`IF`**(국제 대학원 코스워크),
   `fee_year`/`cohort_year` = 2026, `course_area` = `All` 또는 계열 코드(IT는 **`010070`**).
2. ⚠ **JS로 값을 넣고 `.click()` 하면 결과가 안 나온다. POST 직접 호출도 빈 결과다.**
   **`form_input`으로 값을 넣고 Search를 실제 마우스로 클릭해야** 테이블이 뜬다.
3. ⚠ **fee_type을 바꾸고 다시 검색하면 표가 갱신되지 않는다.** 페이지를 새로 열고 처음부터 채울 것.
4. ⚠ **학부와 대학원의 컬럼이 다르다.**
   - 학부(IFUG): `Course Code | Course Name | Total CP | **Fee per CP** | Fee per session`
     → **연간 = Fee per CP × 48** (1 EFTSL = 48CP = 1년 전일제)
   - 대학원(IF): `Course Code | Course Name | Total CP | **Fee per session(24CP)**`
     → **연간 = Fee per session × 2**

**UTS 값은 맞았다** — 반올림 차이뿐이다.
M.Cybersecurity $28,530/세션 → **57,060**(카드 57,100) · M.Artificial Intelligence $27,688 → **55,376**(카드 55,400) ·

**WSU·그리피스·UTS는 원래 학교 자료에서 온 값이었고, 틀린 건 UQ·플린더스(CRICOS 환산) 쪽이다.**

### 🟢 발행된 글이 카드 정정을 따라오지 않던 문제 — 해소 (2026-08-03)

카드는 고쳤는데 **글 본문 표가 옛 숫자를 들고 있었다.** 25편을 카드값과 전수 대조해 고쳤다.

| 글 | 옛 숫자 → 고친 값 |
|---|---|
| `life-entry` | 플린더스 생명공학 38,300→**46,000** · 의료공학 40,400→**47,800** · UQ 생명공학 44,500→**60,952** · UQ 생체공학 50,100→**60,952** |
| `med-tests` | UQ 치의학 85,200→**99,600** · UQ 수의학 76,700→**89,712** · 시드니 수의학 84,200→**80,500** |
| `teaching-english` | 유아교육 학사 35,600·33,200→**35,700 둘 다** · 석사 33,700→**38,100** |
| `business-entry` | WSU 회계 석사 39,300→**39,337** · UQ 상경 석사 48,000→**60,952** |
| `aviation-cost` | UNSW 항공경영 59,800→**61,000** |
| `hospitality` | 호텔스쿨 34,500→**26,000** |

**본문 문장도 같이 고쳤다** — 표만 바꾸면 안 되는 이유가 실제로 나왔다:
- `life-entry` "플린더스가 학비와 영어 모두 가장 낮습니다" → 디킨 45,200이 더 싸다. 영어만 최저로 고치고
  UQ 60,952 단일 밴드를 축으로 한 문장을 덧붙였다. 학부 범위도 38,200~50,500 → **43,500~60,952**.
- `med-tests` "5년 학비만 38만~43만" → **43만~49만 8천**.
- `business-entry` "3만 5천 2백~3만 7천 … 1만 달러 넘게 낮다" → 실제로는 35,868~39,000이고
  UTS 48,800과의 차이가 9,800이라 **"1만 달러 넘게"가 거짓이 된다.** 문장을 다시 썼다.

**대조 방법**: 글의 모든 `AUD $숫자`를 뽑아 진단 `majorData`의 학비 집합과 대조하면
카드에 없는 값이 남는다. 총액·훈련비처럼 정상적으로 안 맞는 것만 걸러내면 낡은 값이 드러난다.

### 🟡 진단 전공 설명(desc)도 같은 문제였다 + 영문 번역 누락

**금액을 인용하는 곳은 카드만이 아니다.** `desc`·`masterDesc`도 학비 범위를 문장으로 들고 있다.
- 물리치료 "3만 7천~5만 5천" → **3만 7천 7백~7만 9천 4백**(UQ 79,370 반영이 빠져 있었다)
- 회계·금융 "3만 5천 2백~3만 7천" → **3만 5천 9백~3만 9천**
- 비즈니스 "3만 5천~4만 9천" → **3만 9천~5만 6천 8백**
- 사이버보안 — 문장이 카드값과 아예 안 맞아 다시 썼다(학사 32,500~40,500 / 석사 57,100·60,952)

⚠ **`desc`를 고치면 `i18n.js`의 키도 같이 고쳐야 한다.** 에디터 노트와 같은 함정이고
이번에 한 번 밟았다(기계·전기 desc를 고쳐 놓고 키를 안 바꿔 영문이 깨졌다).

⚠ **영문 모드에서 한글이 그대로 나가던 문자열이 20여 개 있었다.** `tr()`은 사전에 없으면
원문을 그대로 돌려주므로 조용히 새어 나간다. 전공 설명 3건·학위명 4건·rank/req 12건을 채웠다.
**점검 방법**: `setLang('en')` 후 `majorData`의 degree·rank·req·ielts·desc를 전부 `tr()`에 넣고
결과에 한글이 남는지 본다. 지금은 0이다.

⚠ **`i18n.js`를 고치면 `index.html`의 `?v=` 캐시 버전을 반드시 올릴 것.**
안 올리면 기존 방문자가 옛 사전을 계속 받는다. 실제로 브라우저 검증 중에 이 현상을 봤다.

### ⚠ 라벨도 데이터다 — `rank`의 "최저" 주장

금액을 고치면 `rank: "학비·영어 모두 최저"` 같은 문구가 조용히 거짓이 된다. 이번에 바꾼 것:
생명공학 석사·소프트웨어공학 학부·토목 학부 플린더스는 **"영어 요건 최저"**로 낮췄고
(각각 디킨 45,200 · 그리피스 46,000 · WSU 40,916이 더 싸다),
스윈번은 "EA 인증 · 계열 학비 최저" → **"EA 인증 · 멜버른 도심 캠퍼스"**로 바꿨다.
기계·전기 전공 `desc`의 "연 4만 1천에서 6만 2천"도 4만 7천으로 고쳤다.
**앞으로 학비를 고칠 때는 같은 목록의 rank·desc를 반드시 같이 읽을 것.**

- ~~`social-work`~~ · ~~`physio-ot`~~ · ~~`aviation-cost`~~ · ~~`it-cost`~~ → **숫자가 축인 글 4편 전부 정리 완료.**
